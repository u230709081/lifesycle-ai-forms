# Formika – AI-Powered Form Platform

Formika is a proof-of-concept (POC) for a sector-independent form platform that simplifies form creation and completion using artificial intelligence.

The project aims to make form processes more efficient by combining AI-powered form generation, document analysis, evidence-based answer suggestions, and customer approval.

## Key Features

- **AI Form Generation:** Create forms and questions from natural language descriptions.
- **Multi-Sector Support:** Adaptable form templates for different industries.
- **Document Analysis:** Extract relevant information from uploaded documents.
- **AI-Powered Suggestions:** Generate answers based on available information and show supporting evidence.
- **Customer Approval:** Allow customers to review, approve, or edit suggested answers.
- **Flexible Form Editing:** Customize form questions, sections, and settings.

## Use Cases

- Real Estate
- Human Resources
- Healthcare
- Education
- Hospitality
- Customer Information Collection
- Surveys and Feedback
- Any form-based workflow across different industries

## Getting Started

**Requirements:** Node.js 18.18 or later.

1. Clone the repository.
2. Run `npm start` or execute `Baslat.bat` on Windows.
3. Open `http://localhost:3000` in your browser.

AI-powered features require the relevant API keys to be configured in the `.env` file.

## Project Status

Formika is currently under development as a proof of concept. Its features and supported use cases will evolve throughout the development process.
